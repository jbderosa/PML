# Public sanitization notes

This public alpha tree is deliberately genericized.

Changes made only for the public projection include:

- personal names, locations, organizations, workflow targets and deployment examples replaced with synthetic placeholders;
- deployment timezone defaults changed to UTC;
- public runner log messages do not emit deployment row identifiers;
- the scheduled GitHub Actions workflow is published as an inactive example rather than installed as a live workflow;
- private architecture handoff documents are replaced by generic architecture/audit documentation.

No real credentials, account/resource identifiers, queue contents, result artifacts, private URLs, deployment logs, or personal workflow data are intentionally included.
